# DevOps Practical

## Aim
To understand Version Control using Git and GitHub.

## Introduction
Git is a distributed version control system used to track changes in source code.

GitHub is a cloud-based platform used to host Git repositories and collaborate with developers.

## Objectives
1. Create a GitHub repository.
2. Add and edit project files.
3. Track changes using commits.
4. Maintain project history.

## Tools Used
- Git
- GitHub
